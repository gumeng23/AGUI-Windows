# Agui for VS Code

为 Agui 脚本语言（`.ag` 文件）提供完整编辑体验的 VS Code 扩展。

Agui 用缩进语法描述桌面 GUI，解释器是 `agui.exe`。本扩展把「写代码 → 查错 → 运行 → 打包」串成一条链路。

## 功能

| 功能 | 说明 |
| --- | --- |
| 语法高亮 | 关键字（含中文别名）、字符串、注释、数字、内置函数、控件构造器、事件行、`key=value` 参数名 |
| 语法检查 | 调用 `agui.exe check`，把 `第 N 行第 M 列: 消息` 转成红色波浪线；保存时 / 输入时自动触发 |
| 运行脚本 | 编辑器标题栏 ▶ 或 `Ctrl+F5`，直接启动 GUI，输出进入内置终端 |
| 打包 exe | 标题栏 📦 或 `Ctrl+Alt+B`，调用 `agui build` 生成 `out/<文件名>.exe` |
| 自动补全 | 控件名、内置函数、GUI 函数、事件名、属性与方法（输入 `.` 触发） |
| 悬停提示 | 签名、说明、中文别名的英文原名 |
| 代码片段 | 窗口骨架、事件、函数、条件、遍历、异常、菜单 |

中文关键字别名同样参与高亮与悬停：`如果` `否则如果` `否则` `当` `对于` `在` `函数` `返回` `中断` `继续` `监听` `略过` `尝试` `捕获` `导入` `匿名` `并且` `且` `或者` `或` `非` `真` `假` `空`。

## 快速开始

1. 用 VS Code 打开包含 `.ag` 文件的文件夹（`agui.exe` 放在工作区根目录时无需任何配置）。
2. 打开任意 `.ag` 文件，标题栏右侧会出现 ▶ / ✓ / 📦 三个按钮。
3. 点击 ▶ 运行，GUI 窗口弹出；终端面板里能看到解释器输出与退出码。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `agui.path` | `""` | `agui.exe` 的路径。留空则自动查找；支持 `${workspaceFolder}` 变量；也可以只写 `agui` 交给 PATH 解析 |
| `agui.checkOnSave` | `true` | 保存时做语法检查 |
| `agui.checkOnType` | `true` | 输入时做语法检查（有 700ms 防抖） |
| `agui.checkDelay` | `700` | 输入检查的防抖延迟（毫秒） |
| `agui.buildOutputDir` | `"out"` | 打包输出目录，相对工作区根目录 |
| `agui.buildOptions` | `""` | 追加给 `agui build` 的参数，例如 `--icon app.ico` |

### `agui.exe` 的查找顺序

未配置 `agui.path` 时，按以下目录依次查找 `agui.exe` / `agui.cmd` / `agui.bat` / `agui`：

1. `agui.path` 指定的路径（若是裸文件名则交给 `PATH`）
2. 当前文件所在的工作区根目录
3. 扩展安装目录的上一级、上两级（方便把扩展放进 Agui 仓库内）
4. 环境变量 `AGUI_HOME`
5. 进程当前工作目录

都不存在时会提示，并可直接「选择文件」写入 `agui.path`。

## 命令

| 命令 | 快捷键 | 位置 |
| --- | --- | --- |
| `Agui: 运行脚本` | `Ctrl+F5` | 编辑器标题栏 ▶、编辑器右键、资源管理器右键、命令面板 |
| `Agui: 语法检查` | `Ctrl+Alt+C` | 编辑器标题栏 ✓、编辑器右键、命令面板 |
| `Agui: 打包 exe` | `Ctrl+Alt+B` | 编辑器标题栏 📦、编辑器右键、资源管理器右键、命令面板 |
| `Agui: 选择解释器路径` | — | 命令面板 |

## 语法检查的实现细节

`agui check` 只做词法和语法分析，不执行脚本。扩展会：

1. 把当前编辑器内容写入系统临时目录（这样**未保存的修改**也能检查）；
2. 以工作区根目录为 cwd 运行 `agui check <临时文件>`；
3. 解析 stderr 中的 `文件：第 N 行第 M 列: 消息`，转成 `Diagnostic`（`source: agui`）画在对应字符上；
4. 退出码 0 时清空该文件的诊断。

同时兼容 `test.ag 第3行 错误:不能除以零` 与 `test.ag:3:5: message` 两种写法。

## 开发

```bash
npm install
npm run compile     # tsc
npm run watch       # 增量编译
npm run package     # vsce package --no-dependencies
```

按 `F5` 启动「扩展开发宿主」即可调试；请注意宿主窗口的工作区要指向包含 `.ag` 文件的目录，否则 `agui.path` 需要手动配置。

## 已知限制

- 语法高亮基于 TextMate 正则，不是完整解析器；缩进结构由语言配置的折叠规则近似处理。
- 自动补全不区分控件类型（例如 `window.` 也会提示 `checked`），只按 `.` 后的属性 / 方法全集提示。
- 打包进度在独立终端中展示，进程结束后终端保留（`keepOpen`），需要手动关闭。
- 运行脚本时扩展以「隐藏窗口」方式启动 `agui.exe`（这样不会弹出黑色控制台），因此需要 **Agui 0.2.1 及以上**：旧版本会被 Windows 的 `STARTUPINFO(SW_HIDE)` 规则覆盖，进程在跑但 GUI 窗口不可见。
